Machine Learning Algorithm Comparison on Iris Dataset

Project Overview
This project compares multiple machine learning algorithms on the Iris dataset to identify which algorithm performs best.

Algorithms Used
Decision Tree Classifier
Logistic Regression
K-Nearest Neighbors (KNN)

Dataset
Iris Dataset
Source: Scikit-learn built-in dataset

Technologies Used
Python
Pandas
Scikit-learn
Matplotlib

Steps Performed
1.Loaded the Iris dataset
2.Split dataset into training and testing sets
3.Applied multiple machine learning algorithms
4.Compared accuracy scores
5.Visualized results using graphs

Results
The algorithms were compared based on accuracy scores, and the best-performing algorithm was identified.

Conclusion
This project demonstrates how different machine learning algorithms perform on the same dataset and helps identify the most suitable algorithm for the Iris dataset.
